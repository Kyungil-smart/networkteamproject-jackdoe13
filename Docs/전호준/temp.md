# [상태머신/FSM] 상태 변화 패턴 학습 보고서

**작성일:** 2026-05-13
**작성자:** 전호준
**사용 환경:** Unity 6000.9f1 / VS Code

## 1. 학습 목표
* 유한 상태 기계(FSM)의 개념을 이해하고, 조건에 따라 오브젝트의 행동 상태가 매끄럽게 전환되는 구조를 설계한다.
* `Update` 함수 내에 복잡하게 얽힌 `if-else` 구조를 탈피하여 코드 가독성과 유지보수성을 높인다.

## 2. 구현 내용 및 핵심 로직
* **상황 및 과제:** 
  * 평소에는 지형에 몸을 숨기고(Hide) 있다가, 타겟이 감지되면 찌르듯이 맹렬하게 돌진(Rush)하는 몬스터 패턴 구현.
  * 숨기, 돌진, 대기(재사용 대기시간)의 세 가지 상태를 명확하게 분리하여 제어.
* **해결 방법 (핵심 접근):** 
  * `enum`을 활용하여 상태를 정의하고, `switch` 문을 통해 상태별 진입, 실행, 종료 로직을 캡슐화.

## 3줄 요약
* 플레이어 컨트롤러를 통해 입력이 될 시(키보드, 마우스 버튼 등) 해당 입력은 상태 머신으로 간다. 그러면 해당 입력과 함께 게임 현황의 상태에 따라 상태 머신에도 변화가 생긴다. 그에 변화에 맞게, 게임에서 각 독립된 요소들이 갈아끼워지며 게임상에 표현되는 방식이다.
