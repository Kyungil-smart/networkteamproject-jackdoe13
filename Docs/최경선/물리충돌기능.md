### 물리 충돌 기능

1. 구현 해야할 기능에 대한 공부
   - Rigidbody: 게임 오브젝트의 물리적 동작을 가능하게 하는 주요 컴포넌트. Rigidbody가 연결된 오브젝트는 중력, 속도, 힘이 적용됨.
   - Collider: 물리적 충돌을 위해 게임 오브젝트의 모양을 정의. 
   - (두 기능은 Inspector창의 Add Component를 눌러 추가할 수 있다.)

   - 코드 이해 기록 남기기
     - Collider를 적용하면 벽이 될 수 있음.
     - Rigidbody만 적용된 오브젝트는 Collider가 적용된 오브젝트를 마주해도 통과해버림. 땅을 만들어주고싶으면 Rigidbody가 적용된 오브젝트에 Collider까지 함께 적용시켜줘야함.
