# 1. MonoBehaviour 

## 1-1 개념
1. unity 오브젝트가 동작할 수 있게 해주는 기본 클래스
2. Unity 엔진과 연결되는 사용자 스크립트의 기본 클래스

## 1-2 특징
1. unity 오브젝트가 컴포넌트가 되어 기능을 추가하여 동작할 수 있게 해주는 역할
2. MonoBehaviour에 상속 받지 못한 클래스는 평범한 C# 클래스가 되어 오브젝트에 컴포넌트로 넣을 수 없다.
3. MonoBehaviour가 없으면 기능구현을 했어도 오브젝트에 컴포넌트로 추가 못합니다. 그래서 라이프 사이클이 호출 안돼고, Unity 이벤트 사용이 불가

* 상속: 부모 클래스 기능을 물려받음 *

## 1-3 장점
1. Update() 루프 자동 반복
2. Coroutine()[순차적으로 함수를 시간, 흐름을 설정하여 제어] 기능 사용가능
3. Invoke()[특정 함수를 일정 시간 뒤에 자동 실행하는 기능]을 사용 가능
4. 게임오브젝트에 컴포넌트로 접근하여 사용가능

## 1-4 단점
1. Unity엔진 의존성이이 커서 Unity 이외에 재사용 어려움

## 1-5 MonoBehaviour이 있을 때와 없을 때 차이
1. 있을때: 유니티 게이오브젝트에 컴포넌트
2. 없을때: 데이터 클래스, 계산 클래스
