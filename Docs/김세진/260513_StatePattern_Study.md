상태 패턴의 특징
- Monobehaviour 를 상속받아 Unity 생명주기 구조를 따른 객체가 있다
- 객체 안에 State Machine이 있고 그 State Machine을 통해 State(상태)를 갈아끼우듯 교체하는 방식이다.
- 각 State들은 Monobehaviour를 상속받지 않는 순수 C# Script 이다.
- 그래서 객체안의 Update()와 state안의 Update()는 서로 다른 함수이다.
